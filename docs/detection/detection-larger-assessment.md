## 与参考实现核对

网络 `models/east_model.py`、真值 `components/ground_truth.py`、损失 `components/loss.py` 在本仓库原 detection 与 majorbio 中内容一致，继续显式复用。保留原 Adam、OneCycleLR、梯度裁剪、训练/验证结构、早停与 Top-K，不重新设计算法。

必须修复 majorbio 的图片枚举：有 JPG 时原加载器不会读取 PNG。现在所有支持格式一次性枚举，训练 593 张、验证 189 张全部参与；不存在旧索引排除的 8 张 PDF 图片等隐式过滤。

抽查网页表格 `du20260910-000001.png` 可见密集单元格、蓝色链接、浅灰禁用字、彩色状态、浅色选中行及网格线。采用较弱颜色扰动、背景色补边、完整文字框训练；不随机水平截断单元格，不改变原几何监督。缺失标签直接报错，避免整张有文字的截图成为错误背景样本。

默认采用 1024、batch 2 作为首轮基线：网页中位字高约 7.4px，PDF 中位约 11.7px。1280 分别约 9.2px 和 14.6px，但输入像素量比 1024 多 56%，尚无精度对比证明必须增大。先检查 1024 验证集的小字召回，若漏检集中在小字，再以相同划分对比 1280；网络和输出步长不变。保留正方形等比缩放以兼容纵向 PDF 和横向表格，不统一拉伸到横长矩形。

具体参数差异及理由见 [README](../../detection_larger/README.md)。

训练帮助、代码编译及本次改动范围的空白检查通过。完整测试在收集阶段被已有 `recognition.utils.remove_annotation_outer_quotes` 和 `recognition.utils.rename_synthesis_images` 两个缺失模块阻断，未修改无关识别模块。
