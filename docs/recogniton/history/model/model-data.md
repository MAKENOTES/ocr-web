# 历史模型：张量数据流

> 本文保留旧模型/旧批处理方案的说明，不作为当前实现。原文未注明版本时不可据此修改现有权重或预处理；当前契约见[架构](../../recognition.md)。


### 全程数据流向总结 (以 Batch=16, W=1024 为例)

1. **Input**: `[16, 1, 32, 1024]` (图片)
2. **CNN**: `[16, 512, 1, 256]` (提取特征，宽缩4倍)[model-data-2.md](model-data-2.md)
3. **Squeeze**: `[16, 512, 256]` (去掉高度)
4. **Permute**: `[256, 16, 512]` (宽度变时间步)
5. **RNN**: `[256, 16, 1024]` (假设 nh=512, 双向)
6. **Linear**: `[256, 16, 6001]` (映射到字符集)
7. **LogSoftmax**: `[256, 16, 6001]` (计算对数概率，输出)
