# OCR 术语

本文集中解释 OCR 相关术语及其在本项目中的含义，供代码、操作说明和架构文档统一引用。

| 术语 | 含义及本项目约定 |
| --- | --- |
| stem | 文件名去掉最后一个扩展名，例如 `page.png` 的 stem 为 `page`；检测标签用它配对 |
| bbox4 / xyxy / AABB | 水平矩形的 `x_min y_min x_max y_max`，坐标单位为图片像素 |
| quad8 | 四个顶点的八个坐标；大图检测只接受能组成水平矩形的四点 |
| EAST | 输出文字置信度图和几何距离图的检测结构；本项目几何头只有四个方向，没有角度 |
| log1p / expm1 | `log(1+x)` 及其逆变换；距离在特征图像素单位下编码，解码后再乘步长 |
| 连通域 | 二值置信度图中相邻的正像素集合；四连通不含对角相邻，八连通包含对角相邻 |
| NMS / IoU | 按置信度抑制重复框；两框交集面积除以并集面积 |
| manifest | 样本归属清单；小图检测划分读取已有清单，大图检测直接读取独立目录 |
| NCHW / TBC / BTC | 批次、通道、高、宽；时间、批次、类别；批次、时间、类别。识别输出采用 TBC |
| CRNN / BiGRU | 卷积提取图像序列，再用双向 GRU 处理前后文；当前识别 GRU 为 2 层，层数属于权重契约 |
| CTC / blank | 无需逐字位置标注的序列损失；blank 是编号 0 的空白类别，用于对齐及分隔连续相同字符 |
| UNK | 编号 1 的字典外字符类别；不是 blank，当前解码会输出 `[UNK]` |
| greedy decode | 每步选最大值类别，合并连续重复编号，再移除 blank；不做词典纠错 |
| padding / 保护区 | 为组 batch 增加的背景；识别额外固定保留 32 px 右侧背景供 CNN 使用，不计入有效宽度 |
| PackedSequence | 让循环网络按每张图的有效长度执行，避免反向 GRU 的补边状态污染有效字符 |
| 字典 ABI | 字符内容及顺序决定输出编号含义；类别数相同也不意味着字典兼容 |
| CER / 整行准确率 | 总编辑距离除以总真值字符数；完全相同的预测行数除以总行数。当前评估先去首尾空白 |
| 权重初始化 | 训练开始时随机生成的模型参数；识别训练不加载其他权重 |
| Top-K | 保留指标最优的 K 个检查点；检测按损失，识别按 CER，均越小越好 |
